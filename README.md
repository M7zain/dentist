# عيادة الأسنان — نظام إدارة العيادة

منصة عربية RTL لإدارة مرضى عيادة الأسنان، الإجراءات، الجلسات، والإحصائيات.

## التشغيل

```bash
npm install
npm run db:setup
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

## الميزات

- تسجيل دخول الطبيب
- إضافة مرضى (هاتف سوري +963) وزر واتساب مباشر
- إجراءات علاجية مع السعر والمتبقي
- جلسات مع ملاحظات، مبلغ مدفوع، ومخطط أسنان FDI
- إنهاء الإجراء عند اكتماله
- لوحة إحصائيات (يوم / أسبوع / شهر / مخصص)
- نسبة العيادة وتقسيم الإيراد بين الطبيب والعيادة

## قاعدة البيانات

الإعدادات في `.env.local` (MySQL).
